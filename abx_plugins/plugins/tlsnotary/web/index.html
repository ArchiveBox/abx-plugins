What this proves
A valid artifact binds the captured HTTP response bytes and request to a certificate-authenticated server, the TLS connection time, and the notary’s signature. You must trust the notary not to collude with the person creating the archive. Partial responses are explicitly labelled: omitted bytes are not certified. A byte prefix does not certify a video duration. This does not attest screenshots, rendered DOM, linked assets, or the truth of claims on the page.
The notary receives cryptographic commitments, not your URL path, query string, cookies or page content. It observes your IP, timing and traffic sizes. The artifact itself contains the archived URL and response; anyone you share it with can read them.
Trusted notary key
The key is pinned by this application, never accepted just because a file supplies it. Confirm it independently when the identity of the notary matters.
